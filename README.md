# Портфолио для технического писателя

В этом репозитории собраны примеры разработанной мной технической и пользовательской документации, не являющиеся чувствительными к внутренней корпоративной информации. 

В портфолио продемонстрированы два подхода: **Docs-as-Code** (разметка Markdown, работа с репозиторием) и **классический технический дизайн** в MS Word для объемных документов.

`Контекст: в документах ведется речь о 4D ГИС «Интегра 4D-Планета Земля», разработанной консорциумом Интегра-С. Предметная область организации Интегра-С находится на стыке цифровой безопасности, систем мониторинга и геоинформационных технологий.` 

## 📁 Примеры документации:

* **[Руководство пользователя клиента ССОИ Интегра Планета]**  
  *Описание:* Большое пользовательское руководство по работе с основной системой «Интегра 4D-Планета Земля» (Интегра-Планета). Документ составлялся совместно с отделом инсталляции и отделом тестирования, уточнялись детали по тому или иному функционалу, запрашивались нужные скриншоты.

  *Форматы:* Изначально разрабатывался, а также поддерживается/обновляется в .docx формате. Для удобства просматривания в репозитории приложена копия в .md формате

* **[Описание применения Smart Zone]**  
  *Описание:* Документ, описывающий основной концепт одного из модулей системы Интегра-Планета. Документ разрабатывается для проектировщиков систем безопасности, для корректной настройки и подгонки системы на различных охраняемых объектах. В ходе разработки документации постоянно обсуждаются детали работы модуля совместно с разработчиком, тех.отделом и руководителем отдела разработки.

  *Форматы:* Таким же образом изначально разрабатывается в формате .docx, прикладываю копию в .md.

* **[Инструкция по настройке Nginx Proxy]**  
  *Описание:* Техническое руководство для системных администраторов по развертыванию и конфигурированию прокси-сервера.

  
  `Контекст: На одном из объектов необходимо было настроить передачу данных о качестве атмосферного воздуха в ФГИС «Экомониторинг», для чего было предоставлено наше API. Мною была реализована защита доступа с помощью Nginx proxy, дополнительно попросили составить инструкцию для системных администраторов по развертыванию и конфигурированию данного прокси-сервера.`
  *Формат:* markdown


* **[Инструкция по настройке сервиса синхронизации Two_UDP]**  
  *Описание:* Пошаговый туториал по конфигурации сетевого сервиса на двух машинах с примерами блоков кода.


  `Контекст: Девопс инженером была произведена реализация сервиса синхронизации через однонаправленный шлюз СТРОМ-1000. Необходимо было развернуть сервис на виртуальных машинах, проверить работоспособность и написать для админов и инсталляторов инструкцию как развернуть данный сервис. Мною была изучена задача в redmine, уточнялись детали работы сервиса у девопс инженера, после чего была составлена небольшая инструкция.`
  *Формат:* markdown

## 🛠️ Навыки и инструменты:
* **Разметка и языки:** Markdown, HTML/CSS (базовый).
* **Инструменты:** Git, CLI Pandoc (автоматизация конвертации), VS Code, MS Word.
